# SalamFood

A responsive food ordering UI for browsing restaurants, viewing menus, managing a cart, and placing a dummy checkout order.

**Live demo:** [https://abdullahriax.github.io/SalamFood/](https://abdullahriax.github.io/SalamFood/)

## Features

- Live restaurant listing with search and top-rated filter
- Restaurant menu with add-to-cart
- Cart, dummy checkout, and order confirmation
- Shimmer loading states and mobile-friendly layout
- React, Redux Toolkit, React Router, Tailwind CSS, and Parcel

## Local development

```bash
npm install
npm start
```

Then open the local URL Parcel prints (usually `http://localhost:1234`).

## Production build

```bash
npm run build
```

The app deploys to GitHub Pages from the `main` branch via GitHub Actions.
